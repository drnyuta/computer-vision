Этот проект представляет собой веб-приложение для автоматического определения времени по изображению аналоговых часов с использованием компьютерного зрения.

# Архитектура проекта

Проект состоит из двух основных компонентов, взаимодействующих через HTTP-запросы:

1. Бэкенд (main.py): REST API, разработанный на FastAPI (Python), который использует библиотеку OpenCV для выполнения всех операций по обработке изображений и обнаружению времени.

2. Фронтенд (ClockDetector.jsx): Пользовательский интерфейс на React, который позволяет пользователю загружать изображения, настраивать параметры обнаружения и просматривать результат с пошаговой визуализацией.

## 1. Бэкенд (main.py) — Логика Компьютерного Зрения

Эндпоинт POST /detect принимает изображение и выполняет сложный алгоритм в три этапа.

### А. Этап 1: Обнаружение Циферблата (Clock Face Detection)

Цель — точно определить центр (cx, cy) и радиус (radius) часов.

1. Предварительная обработка: Изображение конвертируется в оттенки серого, и применяется Гауссово размытие для снижения шума.

2. Поиск форм:

    - Контуры и Эллипсы: Используется адаптивная бинаризация для нахождения краев. К замкнутым контурам подбираются эллипсы (cv2.fitEllipse). Неподходящие (слишком вытянутые или маленькие) формы отбрасываются.

    - Круги Хафа (HoughCircles): Также используется для обнаружения идеально круглых форм.

3. Выбор лучшего кандидата: Каждой обнаруженной форме присваивается "оценка" (score), основанная на ее площади и близости к геометрическому центру изображения. Выбирается форма с наивысшей оценкой как наиболее вероятный циферблат.

### Б. Этап 2: Обнаружение Стрелок (Hand Detection)

После фиксации циферблата, алгоритм фокусируется на поиске линий, исходящих из центра.

1. Маскирование и Улучшение: Создается маска, ограничивающая область поиска циферблатом и исключающая центральную втулку.

2. Определение режима стрелок:

    - Пользователь может вручную выбрать, являются ли стрелки темными (dark) или светлыми (light).

    - Если выбран Автоматический режим, алгоритм оценивает среднюю яркость циферблата для определения контраста.

    - Если стрелки темнее фона, изображение инвертируется (cv2.bitwise_not), чтобы сделать стрелки светлыми — это повышает эффективность детектора границ.

3. Выделение границ: Применяются улучшение контраста (CLAHE), размытие и детектор границ Canny для получения четких линий стрелок.

4. Поиск линий Хафа (HoughLinesP): На границах ищется набор прямых линий. Линии фильтруются по длине и началу (они должны исходить из центра).

5. Расчет углов: Для каждой найденной линии определяется ее наконечник и угол относительно 12 часов.

### В. Этап 3: Определение Времени (Time Calculation)

Из всех кандидатов выбираются две самые длинные линии (минутная и часовая стрелки).

1. Идентификация стрелок: Используется комбинация следующих факторов для определения, какая из стрелок минутная, а какая часовая:

    - Длина: Минутная стрелка обычно длиннее.

    - Согласованность углов: Проверяется, насколько положение часовой стрелки соответствует расчетному положению, исходя из угла минутной стрелки (например, при 30 минутах часовая стрелка должна быть на полпути между двумя часовыми метками). Комбинация с наименьшей ошибкой считается правильной.

2. Финальный расчет: Углы преобразуются в часы и минуты.

3. Визуализация: Генерируются три Base64-изображения для отладки и демонстрации: обнаружение циферблата, обнаружение стрелок (с выделением выбранных) и финальный результат с наложенным временем.

## 2. Фронтенд (ClockDetector.jsx) — Пользовательский интерфейс

React-компонент, разработанный с использованием Tailwind CSS, обеспечивает интуитивно понятный интерфейс.

Основные функции:

- Загрузка изображения: Компонент handleUpload обрабатывает загруженный файл, создает локальное превью и сбрасывает предыдущие результаты.

- Выбор режима: Пользователь может выбрать Авто, Темные стрелки или Светлые стрелки через выпадающее меню (handMode). Этот параметр передается в API.

- Обработка API: Функция handleDetect отправляет изображение и выбранный handMode на бэкенд и обрабатывает ответ.

    - В случае успеха отображает время и визуальные шаги.

    - В случае ошибки выводит сообщение пользователю.

- Визуализация шагов: 
    - Detected Ellipse (face_detection)
    - Detected Hands (hands_detection)
    - Final (final_result)
